═══════════════════════════════════════════════════════
PROJECT OVERVIEW
═══════════════════════════════════════════════════════
Build a Warehouse Inventory Management System that allows users to:
- Upload order/delivery sheets (Excel, CSV, PDF) to trigger stock IN or OUT
- Automatically parse uploaded files and update inventory records
- View real-time inventory dashboard with quantity, unit price, total value
- Manage stock-in (入库) and stock-out (出库) operations with full history
- Generate inventory reports and export data

═══════════════════════════════════════════════════════
TECH STACK  (use exactly these)
═══════════════════════════════════════════════════════
Frontend  : React 18 + TypeScript + Vite
UI        : Tailwind CSS + shadcn/ui
State     : Zustand
HTTP      : Axios + React Query (TanStack Query v5)
Charts    : Recharts
File Parse: SheetJS (xlsx) for Excel/CSV on frontend preview

Backend   : Node.js + Express + TypeScript
ORM       : Prisma
Database  : SQLite (dev) — schema must be compatible with PostgreSQL (prod)
File Store: Multer + local /uploads folder
File Parse: xlsx (SheetJS) + pdf-parse on backend
Auth      : JWT (access token 15min + refresh token 7d)
Validation: Zod (shared schemas between frontend and backend)
